【它是什么】
  用 MPU6050 读三轴加速度，算出俯仰角/横滚角，在 0.96 寸 OLED 上画一个
  气泡；摆平时气泡落进靶心、靶心填实、蜂鸣器短鸣一声。

  硬件：STM32F103C8T6 最小系统板 + 4 针 I2C OLED(SSD1306) + MPU6050
        + 有源蜂鸣器 + ST-Link V2

【七步都已完成，每一步都上机实测过】
  第 1 步  OK  工程骨架 + PC13 心跳灯 + SysTick 延时
  第 2 步  OK  软件 I2C 总线扫描（扫到 0x3C 和 0x68）
  第 3 步  OK  OLED 点屏（显存 + 整屏刷新 + 图形基元 + 8x16 字库）
  第 4 步  OK  MPU6050 读原始数据（数值随倾斜变化、温度 26 度）
  第 5 步  OK  开机零点校准 + 姿态解算（水平稳定、倾斜跟随）
  第 6 步  OK  气泡水平仪界面（方向经上机确认准确）
  第 7 步  OK  蜂鸣器提示（带滞回的单次短鸣）+ 收尾

【接线】三块模块都接 3.3V，绝不能接 5V
----------------------------------------------------------------
  OLED（4 针 I2C，丝印顺序 GND VCC SCL SDA）
      GND -> 核心板 GND
      VCC -> 核心板 3.3V
      SCL -> PB6
      SDA -> PB7

  MPU6050（GY-521）
      VCC -> 3.3V
      GND -> GND
      SCL -> PB6    （和 OLED 的 SCL 并在一起）
      SDA -> PB7    （和 OLED 的 SDA 并在一起）
      AD0 -> 悬空即可（模块上已有 4.7k 下拉，地址就是 0x68）
      INT / XDA / XCL -> 不接

  蜂鸣器（3 针：VCC / I-O / GND，低电平触发）
      VCC -> 3.3V
      GND -> GND
      I-O -> PB8

  ST-Link（下载与调试）
      SWDIO -> PA13
      SWCLK -> PA14
      GND   -> GND
      3.3V  -> 不接（核心板自己供电；两个电源不要同时上）

  板载 LED 在 PC13，不用接线。

  注意：OLED 丝印顺序和中景园官方《4 针 B 版结构图》上印的
  （VCC GND SCL SDA）是相反的，所以一定要按你手上模块的丝印接，
  不要照图纸抄。VCC 和 GND 接反会烧模块。

【怎么用】
----------------------------------------------------------------
  1. 接好线，确认无误后上电或按复位。
  2. 头 1 秒钟屏幕显示 CALIBRATING / KEEP IT LEVEL，
     这段时间【板子必须保持水平】—— 零点就是在这一刻定的。
     上电时会先短鸣一声，那是蜂鸣器自检。
  3. 之后进入气泡界面。摆平后气泡落进靶心，会短鸣一声。

  屏幕内容：
  +--------------------------------------------------+
  |                       |  PITCH                    |
  |        ╭─────╮        |  +00.2                    |
  |      ╭─┤  ●  ├─╮      |                           |
  |      │ │     │ │      |  ROLL                     |
  |      ╰─┤     ├─╯      |  -00.8                    |
  |        ╰─────╯        |                           |
  +--------------------------------------------------+

  左半屏：外圈 + 内圈 + 上下左右四个刻度 + 靶心 + 气泡（实心小圆）
          气泡落进靶心时靶心会填实
  右半屏：PITCH / ROLL，单位度，一位小数

  量程：15.0 度对应气泡跑到环内壁，再大就沿原方向贴在壁上。

【想改参数的话，都在 main.c 顶部】
----------------------------------------------------------------
  方向不对：
      PITCH_DIR / ROLL_DIR            数字的正负
      BUBBLE_X_DIR / BUBBLE_Y_DIR     气泡往哪边跑
      改成 -1 即可翻转，只改一个字符。

  灵敏度与手感：
      HUD_FS_X10        满量程，150 表示 15.0 度跑到环内壁。调小更灵敏。
      LPF_SHIFT         滤波强度，4 表示 alpha=1/16。调大更稳但更迟钝。
      SAMPLE_PER_DISPLAY 每次刷屏前采多少个点。调小刷新更快。

  蜂鸣器：
      LEVEL_ENTER_X10   1.0 度以内算水平
      LEVEL_EXIT_X10    2.0 度以外才重新武装（滞回，防止边界反复叫）
      BEEP_HOLD_CYCLES  连续几轮在阈值内才叫
      BEEP_MS           鸣叫时长
      BOOT_BEEP_MS      开机自检短鸣，不想要就设成 0

【几个刻意的设计决定，以及为什么】
----------------------------------------------------------------
  1. 器件宏 STM32F10X_MD / USE_STDPERIPH_DRIVER 写在工程里
     （Options for Target -> C/C++ -> Define），stm32f10x.h 保持原版不动。
     这样换库或者把这份库拿去别的工程都不会踩坑。

  2. OLED 和 MPU6050 共用一条软件 I2C 总线（PB6/PB7），靠地址区分
     （0x3C 和 0x68）。软 I2C 只写一份，而且 PB6/PB7 正好是硬件 I2C1
     的引脚，以后想换成硬件 I2C 不用重新接线。
     两个模块各带 4.7k 上拉，并联后约 2.35k，100kHz 下没问题。

  3. OLED 地址用 7 位写法 0x3C。模块上标的 0x78 是 8 位写地址，
     两者是同一个东西。MPU6050 的 0x68 本身就是 7 位地址。

  4. 整屏刷新是一个 I2C 事务连发 1025 字节，不是一页一个事务，
     所以画面不会闪。代价是一帧约 85ms。

  5. 显存字节的 bit0 对应屏幕最上面一行，和字库约定一致。
     位序若搞反，整屏的字会上下镜像。

  6. MPU6050 不碰 DMP。气泡水平仪是静态应用，加速度直接算倾角就够了；
     DMP 要往芯片灌固件、要拉进一大堆库代码，得不偿失。

  7. ACCEL_CONFIG 写 0x00 而不是 0x01。原厂 51 例程给的 0x01 会打开
     加速度高通滤波，把重力分量滤掉，算倾角就废了。

  8. 三轴和温度是【一次连读 14 字节】拿到的，保证同一时刻采样。

  9. 角度用"相对开机基准的变化量 / 基准 Z"算，而不是用绝对公式。
     分子分母是同一把尺子，所以零偏和标度误差一起被消掉。
     正负 15 度以内小角度近似误差远小于 1%。
     这一点很关键：实测这块模块把 1g 读成约 18400（标准 16384），
     偏高 12.4%，超出正品正负 3% 的公差，多半是克隆芯片。
     用绝对公式算就会整体偏 12%，用相对算法则完全不受影响。

  10. 采样节拍刻意和刷屏解耦：固定每 11ms 采一个点，采满 12 个才刷一次屏。
      如果把滤波放在刷屏循环里，刷新快慢一变滤波截止频率就跟着漂，
      那就不是一个确定的滤波器了。

  11. 气泡做径向限幅（整数开平方），超量程时沿原方向压回环内，
      不会跑到圆环外面。

【排查】
----------------------------------------------------------------
  完全不亮：
      先看 PC13 闪灯报码。稳定的慢心跳=两个器件都在；
      快闪 2 下=只找到 OLED；快闪 3 下=只找到 MPU6050；快闪 5 下=都没找到。
      闪 5 下先查 GND 有没有共地（最常见），再查 SCL/SDA 有没有接反。

  屏幕显示 MPU6050 ERR：
      WHO_AM_I 没读对，右边会显示读到的实际值，正常应该是 104（0x68）。

  屏幕显示 READ ERR：
      探测到了但读数据失败，多半是杜邦线接触不良。

  一上电就"嘀"个不停：
      说明这个蜂鸣器模块的 I/O 悬空时就是低电平。在 I-O 和 3.3V 之间
      加一个 10k 上拉电阻即可。（main 里已经把蜂鸣器初始化放在第一行，
      把悬空窗口压到最短了。）

  水平时气泡不落靶心：
      上电校准时板子没放平。按复位键，保持水平重新来。

  读数慢半拍：
      把 LPF_SHIFT 调小（比如 3），或者把 SAMPLE_PER_DISPLAY 调大。

  画面很暗：
      对比度，oled.c 里 0x81 后面那个 0xCF 调大。

  花屏、随机噪点：
      供电或接线接触不良，重点查 GND；也可以把 i2c.h 里的
      I2C_DELAY_LOOPS 从 20 调大（降低总线速度）。
