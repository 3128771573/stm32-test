# 2026-10-09 多功能仪表版

本版把 STM32F103C8T6 水平仪扩展为温湿度、Flash 记录和调试趋势仪表，并改善显示、灯光与模块恢复。
仓库中的 `level/` 保留原七阶段水平仪工程；本版独立放在 `level_dashboard_2026-10-09/`，不覆盖原工程。

完整说明见 [README](README.md)，首次接线见 [傻瓜接线教程](docs/wiring-beginner.md)，
页面操作见 [接线与验收](docs/dashboard.md)，软件验证记录见 [validation.md](docs/validation.md)。

## 2026-10-10 E 版：开机时长与历史会话

将十页仪表当前工作版发布到本目录。`RUNTIME` 显示本次开机的实时运行时长、开机编号和复位原因；`SESSIONS` 可用旋转编码器逐条查看每次开机记录。日期与 RTC 已移除，无需校时或 VBAT 电池。

W25QXX 事件区为每次开机写入 BOOT，并每分钟写入一次存活检查点。突然断电无法写下最终时长，历史页面使用最近一次检查点作为时长下界；没有检查点时明确显示 `NO CHECKPOINT`。事件区容量有限，旧会话会循环覆盖。启动自检只有在本次 BOOT 写入并读回确认后才显示 `EVENT DONE`。旧事件格式仍能读取，原有传感器日志格式和末尾 64KB 区域保持不变。

固件由 Keil ARM Compiler 5.06 update 7 构建，0 错误、0 警告；map Total ROM 为 31,536 字节，RW+ZI 为 8,048 字节。当前 HEX 的 SHA-256 为 `E5E01E7FB6E05E1369147C6647CB159F22D57C45F70B46F334656BDD6B7F6FB8`。本版新增会话记录已编译，仍需实物验收 Flash 保存和断电后的历史浏览。

本目录 `firmware/level_previous.hex` 保存本次更新前公开的七页版；原七阶段参考工程仍单独保留在仓库 `level/`。
## 相对原水平仪的变化

- 新增 DHT11 温湿度，约每 2.5 秒读取；完整帧校验、超时和旧数据过期均有状态提示。
  修复真实 SPL 的 `EXTI_Init(LineCmd=DISABLE)` 不配置触发寄存器的问题；先配置下降沿，再屏蔽直到接收开始。
  **该修复已由用户烧录实测，温湿度恢复正常。**
- 新增 3.3V W25Q20–W25Q128 Flash 记录，温湿度有效时每分钟自动保存；可选独立按钮可手动保存。
  记录包含温湿度、角度、开机秒数、有效标志与序号；重启扫描后恢复，界面可查看最近 32 条。
- 七页循环切换：`LEVEL`、`CLIMATE`、`HISTORY`、`SYSTEM`、`RAW DATA`、`TREND`、`DEBUG`。
  原始六轴与芯片温度来自 MPU 的一次 14 字节读取；趋势在 RAM 保留约 12 秒，缺失采样留空。
  DEBUG 显示 DHT 原始字节、接收诊断、PWM 计数、编码器电平、实际采样/绘图速率和累计读取错误。
- 根据实物修正编码器接法：蓝色模块引出 `VCC/GND + A/C/B`，**C 是 GND，没有引出的 SW**。
  PB10 留空或另接独立常开按钮，不能接编码器 C。当前 3.3V 供电旋转已确认可用；不要因模块资料标称 5V 就直接改供电。
- 三颗 LED 改为 TIM1 三通道 **2kHz、3600 级硬件 PWM**，加入视觉补偿、缓起缓落与换色渐变。
  首页红灯随径向偏移 `sqrt(P²+R²)` 增亮、绿灯减暗，15° 封顶；中心红灯熄灭。
- OLED 日常页面移除常驻页码、底栏和操作提示，详细诊断集中到 DEBUG。
  首页气泡与圆盘放大，加入轮廓、高光、Q8 位置缓动与像素滞回；大号有效数字固定小数点位置，避免正负和位数变化时左右跳动。
- 连续自适应滤波保留相对开机基准，适配手上 MPU 克隆芯片的偏高读数。
  目标 5ms 采样、首页 33ms 绘图；32 字节差分刷新穿插主循环任务。
  校准检查运动并后台执行，蜂鸣、心跳、DHT 接收和 Flash 等待不阻止翻页；MPU 配置回读与通信失败重试保留。

## 本轮四项优化

1. **只有旋转也能浏览记录。** HISTORY 有记录时停留约 0.8 秒自动进入 BROWSE。
   正向旋转选更旧记录，负向选更新记录；在最新记录继续向更新方向旋转进入 CLIMATE，
   在最旧记录继续向更旧方向旋转进入 SYSTEM。没有记录仍可正常翻页，只有一条时也能从两端退出。
   PB10 独立按钮仍可手动切换浏览、保存数据或长按回首页，未接按钮也能自动记录和浏览。
2. **静置渐暗与动作唤醒。** 板子放稳且无操作约 45 秒，对比度从 `0xCF` 渐降到 `0x28`，画面保持可见。
   旋转、按钮或相对静置基线累计至少 0.3° 的角度变化恢复亮度；校准和当前故障提示保持亮屏。
   传感器读取、趋势采集和自动记录继续运行，慢慢倾斜也可唤醒。
3. **拒绝倒置时的假水平。** 原始 Z 为负显示 `FLIP BOARD`；原始或滤波 Z 低于校准 Z 的四分之一显示 `TILT RANGE`。
   无效姿态取消水平锁存并关闭水平提示蜂鸣，趋势留空，保存记录不标角度有效；RAW DATA 仍可查看。
   放回正常正面范围后恢复，开机零点不变。角度算法仍是水平附近的小角度近似，不等于工厂标定的绝对水平。
4. **OLED 运行断线恢复。** 刷新或对比度写入失败后暂停刷新，以约 500ms 间隔尝试重配置。
   16 条完整初始化命令逐条检查 ACK，每次后台服务最多一笔 I2C 事务，失败从头重试；完成后强制完整补刷。
   保留当前显存，不同步阻塞其他任务；修正长期静置后首次唤醒可能被旧截止时间阻塞的问题。

## 新增引脚简表

原有接线保持：OLED/MPU 共用 PB6=SCL、PB7=SDA，蜂鸣器 PB8；SWD PA13/PA14。
所有模块共地；本版使用 3.3V 信号与上拉，不适用于 1.8V Flash 或直接带 5V 信号上拉的模块。

| 器件 | 引脚 | STM32 / 连接 |
|---|---|---|
| W25QXX | CS、CLK、DO/MISO、DI/MOSI | PA4、PA5、PA6、PA7 |
| W25QXX | VCC、GND | 3.3V、GND |
| W25QXX | WP、HOLD | 上拉到 3.3V；模块已有上拉可不重复，不能悬空 |
| DHT11 三针小板 | VCC、DAT、GND | 3.3V、PA1、GND |
| DHT11 裸器件 | DATA 上拉 | 4.7kΩ 接 DATA 与 3.3V 之间；模块已有上拉无需重复 |
| 实物编码器模块 | A、C、B | PB0、GND、PB1 |
| 实物编码器模块 | VCC、GND | 保持当前 3.3V、GND；不是按钮两端 |
| 可选独立常开按钮 | 两端 | PB10、GND；内部上拉，未接时 PB10 留空 |
| 红、绿、蓝 LED | 阳极 | PA8、PA9、PA10，**每颗各串 330Ω** |
| 红、绿、蓝 LED | 阴极 | GND；当前适配独立 LED / 共阴 RGB |

## 升级与回退

- 直接烧录 [firmware/level.hex](firmware/level.hex)，无需重新编译；源码在本目录 `USER/`，Keil 工程见 `README`。
- 对照或回退可烧录 [firmware/level_previous.hex](firmware/level_previous.hex)。
  **该文件是上一轮七页简洁 UI 多功能固件，不是原七阶段 `level/` 固件。** 原水平仪工程继续保留在仓库 `level/`。
- Flash 仍仅使用芯片**末尾 64KB**，32 字节记录、CRC32 和最后提交字节的已有格式不变；升级不要求清空既有本工程日志。
  非本工程格式的非空内容触发 `LOCKED`，不自动格式化、不全片擦除、不自动解除写保护。
  擦除中的旧扇区可能在掉电时丢失，未完整提交的记录不会当作正常数据显示。
- 日志中的时间是记录时的开机秒数，不是日期；趋势只在 RAM，重启清空。

## 可观测验收

1. 上电把板子放稳，完成校准后气泡居中；缓慢倾斜、换方向和过零，数字小数点保持位置，气泡不越过圆盘。
2. 首页逐渐偏离中心，红灯渐亮、绿灯渐暗；相同径向偏移的不同方向亮度相近，回中心红灯平滑熄灭。
3. CLIMATE 等几秒出现温湿度；DEBUG 正常帧应为 `E0/N42`。拔开 DATA 后先显示旧值、过期显示等待，接回恢复。
4. SYSTEM 查看 Flash ID、容量和 READY；有效温湿度保持约一分钟后记录数增加。重启后原记录仍可看，序号继续。
5. HISTORY 停留约 0.8 秒进入 BROWSE，旋转选择新旧记录；最新端向更新方向退出到 CLIMATE，最旧端向更旧方向退出到 SYSTEM。
   没有记录时能继续翻页，只有一条时两个方向均能退出；全过程不要求按钮。
6. 板子静置且无操作约 45 秒观察渐暗；旋转、可选按钮或慢慢累计倾斜至少 0.3° 后恢复亮度。
7. 校准后翻面显示 FLIP BOARD，大幅倾斜到低 Z 范围显示 TILT RANGE；不出现假 LEVEL 或水平鸣叫，RAW 仍有原值，趋势对应时间留空。
8. OLED 运行中掉线再接回，观察重配置后的完整补刷，同时检查其他任务仍运行。
   接线操作先断电；确需带电做掉线验收时仅操作明确的模块连接，避免电源短路。
9. 连续翻页、倾斜、温湿度更新和记录保存期间检查没有卡死；实际采样/绘图速率看 DEBUG 的 S/F。
