# 多功能仪表：接线、页面与验收

第一次接线请先看 [一步一步接线教程](wiring-beginner.md)，按已确认的实物模块丝印接线。

实物照片补充：用户当前编码器是蓝色 VCC/GND + A/C/B 模块，C 为 GND，未引出独立 SW。
该模块不能套用裸编码器的按压接法；PB10 留空或接独立常开按钮（另一端 GND），VCC/GND 保持电源用途。
当前 3.3V 供电旋转已由用户确认可用；模块资料标称 5V，未核对板载上拉前不改为 5V。

当前方案：VCC/GND + A/C/B 编码器模块（无引出的 SW）、DHT11 三针小板、3.3V 标准 SPI W25Q20–W25Q128、红绿蓝三个独立 LED。
PB10 可另接独立按钮。具体 Flash 型号由用户稍后补充，本版自动识别支持范围内的容量，其他 ID 显示 UNSUP，不尝试擦写。
OLED 仍是原来的单色 128×64 屏，颜色来自外部 LED。

## 完整新增接线

原接线不变：OLED 和 MPU6050 的 SCL/SDA 用 PB6/PB7，蜂鸣器 PB8，SWD 用 PA13/PA14。

| 新器件引脚 | STM32 | 说明 |
|---|---|---|
| W25QXX CS / NSS | PA4 | 片选，低有效 |
| W25QXX CLK / SCK | PA5 | SPI1 时钟，当前约 4.5MHz |
| W25QXX DO / MISO | PA6 | Flash 输出到 MCU |
| W25QXX DI / MOSI | PA7 | MCU 输出到 Flash |
| W25QXX VCC / GND | 3.3V / GND | 标准 3.3V 模块；不支持 1.8V 裸芯片 |
| W25QXX WP / HOLD | 3.3V | 若模块已有上拉可不另接；不得悬空 |
| DHT11 DATA | PA1 | 加 4.7k 上拉到 3.3V；模块已有上拉时无需重复 |
| DHT11 VCC / GND | 3.3V / GND | 按模块丝印，3.3V 用短线 |
| 编码器 A / CLK | PB0 | 内部上拉 |
| 编码器 B / DT | PB1 | 内部上拉 |
| 独立按钮 / 引出的 SW（可选） | PB10 | 内部上拉，按下接 GND；当前实物编码器没有此接口 |
| 编码器模块 + / GND | 3.3V / GND | 当前模块 C 也接 GND；裸 EC11 的 A/B 公共端接 GND |
| 红 LED 阳极 | PA8，经 330Ω 电阻 | LED 阴极接 GND |
| 绿 LED 阳极 | PA9，经 330Ω 电阻 | LED 阴极接 GND |
| 蓝 LED 阳极 | PA10，经 330Ω 电阻 | LED 阴极接 GND |

每个 LED 单独串限流电阻；代码当前适配三个独立 LED，或分别有限流的共阴 RGB。
共阳 RGB、带反相驱动的灯板需要改输出极性。LED 没接也不影响其他功能。
裸 DHT11 看栅格正面通常 1=VCC、2=DATA、3=NC、4=GND；最终以器件资料和丝印为准。
新增模块均按 3.3V 方案设计，未引入 5V 上拉。

## 操作和页面

| 操作 | 效果 |
|---|---|
| 左右旋转 | 七页循环切换；快速连续旋转仍用于翻页 |
| 历史页有记录时停留约 0.8 秒 | 自动进入记录浏览，标题变为 BROWSE，无需按键 |
| 浏览模式正向 / 负向旋转 | 选择更旧 / 更新记录；最近 32 条有效记录可选 |
| 最新记录继续向更新方向旋转 | 退出浏览并进入 CLIMATE |
| 最旧记录继续向更旧方向旋转 | 退出浏览并进入 SYSTEM |
| 水平仪 / 温湿度 / 系统页短按独立按钮 | 手动保存当前可用数据，显示 SAVING / SAVED |
| 历史页短按独立按钮 | 手动进入 / 退出浏览；手动退出后本次停留不再自动进入 |
| 按住独立按钮约 0.8 秒 | 回水平仪首页；松手不会再保存一次 |

无记录时不进入浏览；仅一条记录时两个方向继续旋转均可离开历史页。
当前实物编码器没有引出的按压开关，表中短按 / 长按操作仅在另接 PB10 按钮时可用；自动记录和历史浏览不要求按钮。

七页内容：

1. **LEVEL**：大圆盘与双层气泡、俯仰 / 横滚，右上 LEVEL / TILT；校准显示 HOLD STILL 和细进度条，校准失败显示 PLACE FLAT，MPU 故障显示 CHECK SENSOR。
2. **CLIMATE**：温度和湿度、大号数值、单位；无数据显示 --，短时失败保留旧值并标 OLD，过期显示 -- / WAIT；详细故障码看 DEBUG。
3. **HISTORY**：记录序号、浏览位置、温湿度、当时角度和采集时的开机秒数。
4. **SYSTEM**：MPU / DHT 状态、Flash 容量、JEDEC ID、记录总数和当前开机秒数。
5. **RAW DATA**：未经过软件滤波的 AX/AY/AZ、GX/GY/GZ，均为有符号寄存器原值；底部为 MPU 芯片温度寄存器原值，不能当 DHT 环境温度直接读。
6. **TREND**：上图俯仰 P、下图横滚 R，左旧右新，最近约 12 秒；每 100ms 记录一点，两图共用自动量程（最小 ±2°）。断线、校准或漏采时留空，不连接跨越缺失数据的曲线。离开页面仍采集趋势，重启清空，趋势不写 Flash。
7. **DEBUG**：D 为最近一帧完整 DHT 的五个十六进制字节（湿度整数/小数、温度整数/小数、校验）；完整帧仍需通过校验才算测量有效。无完整帧时明确提示。E/N/P 的含义见后文诊断表，TRY 此页只显示末三位以适配屏幕。

DEBUG 的 R/G/B 为 TIM1 PWM 占空计数（0–3600），不是百分数；AB 是 PB0/PB1 两位编码器电平（0–3），K 是消抖后的按钮状态（1=按住）。
S 是最近约一秒的 MPU 成功采样次数折算为每秒，F 是画面生成次数折算为每秒，不代表 OLED 硬件原子整帧刷新率。
MPU ERR 累计运行中尝试读取但失败的次数；重启归零，初始化失败未发起读取不计入。
MPU 数据现一次连读 14 字节，六轴与温度来自同一次事务；显示阶段不另发 I2C 读取，避免为了调试重复采样。

日常页面以留白和主要数值为主，取消常驻页码、底部圆点、TURN PAGE 提示和上下分隔线。
首页圆盘直径 56px、气泡直径 12px，用四个小定位角标记中心；位置采用 Q8 精度，保留 15° 满量程和方向。
绘图缓动约 45ms，像素滞回避免临界位置来回跳，切回首页立即采用当前位置；首页目标约 30Hz，实际速率看 DEBUG 的 F。
保存、长按等提示临时覆盖右上区域。水平仪缺失不会阻止进入其他页，调试数据仍保留在 RAW DATA / TREND / DEBUG。
首页、CLIMATE 和 HISTORY 的大号有效数值右对齐为五个字符位，小数点固定在第四位；首页超过 ±99.9° 时仍显示 OVER。
编码器每一完整四边沿周期翻一格；若实际 EC11 每卡点只有两边沿，把 controls.h 的 ENCODER_EDGES_PER_STEP 改成 2。
方向相反时互换 PB0/PB1 两根线。

## 姿态范围与静置渐暗

角度算法仍为水平附近的小角度近似，开机零点不等于工厂标定的绝对水平。
运行中 Z 分量为负时首页显示 FLIP BOARD；原始或滤波 Z 分量小于校准 Z 的四分之一时显示 TILT RANGE。
这些姿态不确认水平、不触发水平提示鸣叫，记录中角度字段不标为有效；仍可读取和查看 RAW DATA。
放回正面朝上的正常范围后恢复角度显示，原开机零点不变。

静置 45 秒后 OLED 对比度从 0xCF 渐降到 0x28，画面保持显示，传感器、趋势和自动记录继续工作。
旋转或按钮动作、相对静置基线累计至少 0.3° 的角度变化以及故障提示会恢复亮度；校准和故障提示保持亮屏。
唤醒比较累计角度差，慢慢倾斜也能触发，不要求突然晃动。

OLED 运行中写失败不确认显示缓存，以 500ms 间隔尝试逐条检查 ACK 的重新配置，成功后完整补刷。
重新配置仍在主循环执行；未宣称 OLED 能原子切换整帧。掉线恢复和渐暗观感需板上验收。

## 三色状态灯

- 首页有有效角度时：按 sqrt(P²+R²) 计算径向偏移，0° 红灯全灭、绿灯最亮；偏移增加红灯渐亮、绿灯渐暗，15° 封顶。方向反转但距离相同，亮度相同。
- 首页的偏移亮度使用视觉补偿和约 60ms 平滑，不叠加呼吸，避免同一个偏移对应忽明忽暗的亮度。水平判定与蜂鸣器仍沿用原来的阈值和滞回。
- 其他页蓝色柔和呼吸：工作中 / 未处于水平 / 正在校准；确认水平时绿色呼吸。
- 绿蓝同时亮：Flash 正在保存。
- 红色柔和脉冲：当前页相关器件异常或记录区域被锁定。

PA8/PA9/PA10 改用 TIM1 CH1/CH2/CH3 硬件 PWM：当前 72MHz 定时器时钟、PSC=9、ARR=3599，频率 2kHz，3600 级占空比。
SysTick 每 5ms 更新一次亮度包络，载波由硬件持续输出；不再用 GPIO 软件开关产生 100Hz、9 档 PWM。
正常蓝/绿呼吸周期 3 秒，红色故障脉冲周期 1.6 秒；缓起缓落并做近似 gamma=2 的视觉亮度补偿。
颜色切换用 300ms 渐变，保存时绿蓝提示至少保持约 500ms（故障提示可优先打断）。
三颗裸 LED 使用不同峰值以减轻亮度差异，仍各自串联 330Ω；无需改接线。
TIM1 专用于 LED，TIM2 继续用于 DHT / 微秒计时，没有增加 PWM 中断或阻塞延时。

## 温湿度时序

DHT11 上电至少等 2 秒，之后每 2.5 秒请求一次。
主机用开漏输出拉低 20ms 在后台等待，释放后明确切换 PA1 为输入上拉，由 EXTI1 下降沿中断接收；TIM2 的 1MHz 计数测量脉冲间隔。裸器件仍建议外加 4.7k 上拉。
40 位接收不关闭全局中断，不用等待整帧的死循环；10ms 未完成便超时。
校验和、整数 / 小数位、负温度编码及合理范围都检查。最后有效值超过 6 秒便失效。
DHT11 的数据本身是此前一次内部测量结果；页面按该器件能力更新，不是实时高速温度曲线。

实现依据：[奥松 DHT11 V1.3 产品手册](https://www.aosong.com/userfiles/files/media/DHT11-V1_3%E8%AF%B4%E6%98%8E%E4%B9%A6%EF%BC%88%E8%AF%A6%E7%BB%86%E7%89%88%EF%BC%89.pdf)。
该版支持 3.3–5.5V、测量间隔大于 2 秒；用户若拿到更早版本或不同模块，请补充型号再核对供电。

## Flash 记录

- 使用 SPI1，与 OLED / MPU 的软件 I2C 分开；CS / WP / HOLD 接好后，系统页应显示实际 ID 和容量。
- 支持标准 EF40xx / EF70xx，容量码 0x12–0x18，对应 W25Q20 / 40 / 80 / 16 / 32 / 64 / 128。
  例如 EF4017 = 8MB，EF4018 = 16MB。W25Q256 及以上当前显示 UNSUP，避免 24 位地址回绕。
- **仅使用 Flash 末尾 64KB**，16 个 4KB 扇区、每扇区 128 条 32 字节记录。
  其他区域不写、不擦；不使用全片擦除，也不自动解除写保护。
- 上电逐条扫描 CRC 和提交标记，恢复序号、总数和最新记录。
  此区域若发现非本工程格式的非空数据，进入 LOCKED，仍能使用其他页面。
- 温湿度有效时每分钟自动记录一次；短按也能手动记录。只有角度有效时手动保存角度，环境字段标为无效。
- 记录包含序号、开机秒数、温湿度、角度、有效位、CRC32 和提交标记。
  先写正文并回读，再单独写提交字节；断电留下的未提交记录不会显示为正常记录。
- 擦除和编程仅发送启动命令；后续任务轮询状态，有截止时间；等待期间照常翻页和采样。
- 按扇区循环覆盖最旧数据，总有效条数通常在 1921–2048 之间；界面直接浏览最近 32 条。
  1 分钟记录一次约保留 32–34 小时，额外手动保存会缩短覆盖时间。
- 显示的 UP 是记录时的开机时间，不是日期；本机没有 RTC。序号会跨重启继续递增。
- 掉电正在擦除的旧扇区可能丢失；这不是双芯片备份。新记录以完整校验和提交标记为准。

接口参考：[Winbond 官方 W25Q128JV 数据手册入口](https://www.winbond.com/hq/support/documentation/?__locale=en&category=%2F.categories%2Fresources%2Fdatasheet%2F&family=%2Fproduct%2Fcode-storage-flash-memory%2Fserial-nor-flash%2Findex.html&line=%2Fproduct%2Fcode-storage-flash-memory%2Findex.html&pno=W25Q128JV)，
以及工作区 files/模块资料/14-W25QXX Flash闪存/参考资料 中的厂商手册。

## 可观测验收

1. **只接原三模块**：烧录后水平仪仍可用，能转到七页；温湿度显示 --，系统 Flash 显示 ABSENT，不能假显示测量结果。
2. **加编码器**：每格翻一页，快速转动不出现异常页码；历史页有记录时停留约 0.8 秒自动浏览。独立按钮为可选，接上后检查短按切换浏览、长按回首页和释放不多保存。
3. **加三 LED**：首页从居中慢慢倾斜，红灯渐亮、绿灯渐暗；同一角度左右倾斜亮度相近，回中心红灯平滑熄灭。其他页呼吸，保存时绿蓝，故障页红色柔和脉冲。
4. **加 DHT11**：等几秒温湿度出值，连续翻页不影响更新；拔开 DATA，先 OLD，过期后 -- / WAIT，DEBUG 显示错误码，接回后自动恢复。
5. **加 W25QXX**：系统页显示正确 ID / 容量和 READY；温湿度有效时约每分钟自动记录。接了独立按钮时，短按后先 SAVING 再 SAVED，记录数增加。
6. **浏览**：切到历史页停留约 0.8 秒后旋转选择记录；最新 / 最旧两端继续旋转分别进入 CLIMATE / SYSTEM；开机秒数与保存时刻一致。无记录时正常翻页，只有一条时两端也能退出。
7. **断电重启**：此前保存的记录仍可看，序号继续递增；一条未完整提交的记录不得显示为正常数据。
8. **多任务手感**：气泡跟随时翻页、保存记录、温湿度更新都不死机；实际编码器卡点、DHT 时序、灯光和总线速度以板上验收为准。
9. **调试页面**：RAW DATA 静止时 AZ 应接近手上克隆芯片的实际值（约 18400），旋转时陀螺原值变化。TREND 连续倾斜出现两条曲线，恢复居中后回到零线；DEBUG 的 S/F 更新，DHT 正常时显示真实五字节与 E0/N42。
10. **数字稳定**：角度经过正负零点、9.9° / 10.0° 时小数点位置不变；温湿度大号数值也保持同一小数点列。
11. **姿态保护**：校准后倒置 / 大幅倾斜，首页分别显示 FLIP BOARD / TILT RANGE，不出现虚假 LEVEL 或水平提示鸣叫；恢复正常姿态后继续工作。
12. **静置与恢复**：不操作且板子放稳 45 秒，屏幕渐暗；旋转、按键或累计倾斜至少 0.3° 后恢复。OLED 运行掉线再接回，重配置后完整补刷。

型号确认后可调整 Flash 支持范围、DHT 版本、编码器每卡点边沿数或 RGB 极性；引脚默认表已完整可接。

## 温湿度 / 按压无反应时的诊断（2026-10-09）

若另接 PB10 独立按钮，按住超过消抖时间会在任意页面右上显示 KEY DOWN；当前编码器本身没有可用的 SW。
DEBUG 页的 K1 / K0 表示按住 / 松开。短按在松手后执行；长按约 0.8 秒返回首页并提示 HOME。
这些反馈不依赖 Flash 是否接好。

若按住仍为 K0：断电，拔开 PB10 原来的编码器线；重新上电后，用跳线将核心板 PB10 短暂连到 GND。
应出现 KEY DOWN；在 CLIMATE 页保持约 1 秒，应回 LEVEL。
此测试仅对配置为输入上拉的 PB10 接 GND，不接电源、不碰其他 GPIO。
测试通过说明 MCU 输入和程序能响应，继续核对独立按钮两端是否分别接 PB10、GND，以及按下时通断是否正常。
测试不通过时检查烧录的 hex、实际引脚是否 PB10，以及核心板丝印。

DEBUG 显示完整诊断行，例如 E3 N0 P1 TRY2；CLIMATE 只显示等待或旧值状态：

| 字段 | 意义 |
|---|---|
| E1 | 收到完整数据但校验和不符 |
| E2 | 数据编码或温湿度范围不合理 |
| E3 | 接收超时；N0 表示未捕获任何传感器下降沿 |
| E4 | 脉冲间隔不符预期；检查接触、上拉、短线和器件型号 |
| E5 | 接收超时，且请求前 DATA 已经为低；先查 DATA 对地短接、接反或传感器持续拉低 |
| N | 最近一次接收的下降沿处理计数，正常完整帧为 42 |
| P | 最近一次请求前 PA1 电平，正常空闲为 1 |
| TRY | 请求次数；约每 2.5 秒增加，证明后台仍在读取 |

E3 N0 P1 时，PA1 高电平本身不能证明传感器已接通：内部上拉使断线也可能读高。
先确认 DATA 实际接 PA1、模块 VCC/GND 供电、共地，以及裸器件 DATA 到 3.3V 的 4.7k 上拉。
