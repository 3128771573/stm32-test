# 新模块接线：一步一步照着接

适用于当前 level 固件。旧 OLED / MPU6050 / 蜂鸣器接线保持不变。
新增引脚已经写在固件里，不需要因为接了模块再修改程序。

## 已按实物照片确认：用户当前的编码器模块

2026-10-09 实物为蓝色小板，一侧 VCC/GND，另一侧 A/C/B，与工作区的旋转编码器模块说明图一致。
说明图标明 C 为 GND，没有引出的独立按压 SW。
下面关于“裸五脚编码器另两脚为开关”的说明只适用于裸器件，不适用于用户这块模块。

当前接法：VCC 接 3.3V（当前旋转实测可用），GND 接 GND，A 接 PB0，C 接 GND，B 接 PB1。
不要将 VCC/GND 当作按压两脚；不要将 C 接 PB10，否则程序会始终显示 KEY DOWN。
PB10 暂时不接；需要保存/回首页操作时，另加独立常开按钮，一端 PB10、另一端 GND。
没有按钮也能查看旧记录：转到 HISTORY 后停留约 0.8 秒，标题变为 BROWSE，再旋转选择记录。
正向旋转选更旧的，负向旋转选更新的；最新记录继续向更新方向转回 CLIMATE，最旧继续向更旧方向转到 SYSTEM。
快速连续旋转仍可翻页，没有记录时不进入浏览。若接了独立按钮，短按仍可手动进出浏览；手动退出后本次不再自动进入。
资料标称模块 DC 5V，但不要未经电路确认直接改为 5V，以免板载上拉把信号拉到 5V。
参考：[本地模块说明图](../../files/模块资料/11-旋转编码器/旋转编码器模块使用说明.png)。

没有万用表时，断电拔掉 PB10 原线，再上电：KEY DOWN 应消失，DEBUG 的 K 应为 0。
用跳线把 PB10 短暂接 GND，出现 KEY DOWN；松开消失，等效验证外部按钮接口。
DHT11 丝印被遮挡时先断电，单独拍模块正反面，不按杜邦线颜色猜引脚。

## 第 0 步：其他裸编码器的辨认参考

用户当前模块按上面的实物接法使用，不需要本步骤。仅更换为裸五脚 EC11 时再参考以下辨认。
常见结构是：A/B 为旋转信号，C 为公共端，另两脚为按压开关。它不需要供电。

**先断电，用万用表通断档确认另外两脚：**

1. 编码器不接任何板子，黑红表笔分别碰那两脚。
2. 不按：不通，一般不响、显示 OL。
3. 按下旋钮：导通，一般响、显示接近 0 欧。
4. 松开：重新不通。

符合这个现象，就按下面“裸编码器”接法接。
如果另外两脚真的印着 + / − / VCC / GND，或者按下也不导通，先发清晰照片确认；
不要把未知脚当开关接，也不要尝试把 3.3V 和 GND 跨接在它们上。
有些器件有灯或小电路板，接法会不同。
两侧较粗的金属固定脚也不是默认的电源脚。

参考结构：[Alps EC11 带按压开关产品资料](https://tech.alpsalpine.com/e/products/detail/EC11E15244B2/)。

## 第 1 步：准备材料，认识面包板

准备：杜邦线、面包板、普通红/绿/蓝 LED 各一个。

| 电阻 | 数量 | 用途 |
|---|---:|---|
| 330Ω | 3 | 三颗裸 LED，每颗一只，必须串联 |
| 4.7kΩ | 1 | DHT11 DATA 上拉；模块已有上拉时可不加 |
| 10kΩ | 2 | Flash WP / HOLD 上拉；模块已有上拉时可不加 |

电阻没有正负，两头可以交换。普通 1/4W 电阻即可。
色环不好认就断电后用万用表电阻档测：约 330、4700、10000 欧分别对应上述三种。
330Ω 不是 330kΩ；4.7kΩ 是 4700Ω。

面包板常见连接规律：

- 中间区域每横排 5 个孔内部连通，中间沟槽两边不连通。
- 两脚电阻要插在两个不同的连通组；插进同一排等于被短接，电阻不起作用。
- 两根相邻的 LED 脚、模块脚也不能落进同一连通组。
- 红蓝电源长轨可能在中间断开，左右两侧也常常不相通，先用万用表确认。

**每次增减接线前拔掉核心板电源和 ST-Link，接完再上电。**
核心板自己供电时，ST-Link 只接 SWDIO、SWCLK、GND，不再接 ST-Link 的 3.3V。

## 第 2 步：建两条公共电源线

核心板 3.3V 接面包板的一条红轨，核心板 GND 接一条蓝轨。
后文“接 3.3V / GND”都指这两条轨。
只使用你确实接通的那段电源轨，远端不通时用跳线桥接。

```text
核心板 3.3V ── 红轨 ── DHT11 VCC、Flash VCC、各上拉电阻
核心板 GND  ── 蓝轨 ── DHT11 GND、Flash GND、编码器 C、LED 阴极
```

这些电源脚不用串电阻。面包板上标着“+”不代表它自动有电，必须接到核心板 3.3V。
保留原三个模块的电源和信号接线；所有模块的 GND 最终必须相通。

## 第 3 步：接裸编码器，先验收翻页

**只对第 0 步已确认的 A/C/B + 按压两脚编码器使用下表。**

| 编码器脚 | 接到 |
|---|---|
| A | 核心板 PB0 |
| C | GND 蓝轨 |
| B | 核心板 PB1 |
| 按压两脚中的任意一脚 | 核心板 PB10 |
| 按压另一脚 | GND 蓝轨 |

```text
三脚： A ─ PB0    C ─ GND    B ─ PB1
两脚： 一脚 ─ PB10          另一脚 ─ GND
```

**裸编码器不接 3.3V，也不接 5V。**
这五根线直接连接，不串电阻；程序已为 PB0/PB1/PB10 开启内部上拉，先不用外加上拉。
按压两脚没有正负，可以互换；A/B 不要和 C 搞混。
初次接线尽量短，先用约 10–20cm 杜邦线。

上电并烧录当前 level.hex 后：

1. 旋转，页头应在 LEVEL / CLIMATE / HISTORY / SYSTEM / RAW DATA / TREND / DEBUG / STROBE 之间改变。
2. 按住约 0.8 秒，应回 LEVEL；松开不应再触发短按。
3. 转动方向反了，断电后交换 A、B 两根线。
4. 如果每转两格才换一页，不是电源问题，可能是编码器每卡点边沿数不同；反馈现象再调固件参数。

先把翻页验收通过，再接后面的模块。

## 第 4 步：接三颗 LED 和三只 330Ω

这里按普通两脚裸 LED 接。通常长脚是阳极（+），短脚或外壳平边对应阴极（−）。
脚已剪短、封装特殊或分不清时，用万用表二极管档确认，不凭脚长猜。

每颗 LED 一条独立线路：

```text
PA8  ── 330Ω ── 红 LED 阳极 ── 红 LED 阴极 ── GND
PA9  ── 330Ω ── 绿 LED 阳极 ── 绿 LED 阴极 ── GND
PA10 ── 330Ω ── 蓝 LED 阳极 ── 蓝 LED 阴极 ── GND
```

具体操作，以红灯为例：

1. 红 LED 两脚插到面包板两个不相通的横排。
2. 短脚所在排用线接 GND。
3. 330Ω 一头插到长脚所在排，另一头插到另一个空排。
4. PA8 用线接到这个电阻另一头所在的空排。
5. 绿灯重复一次，把 PA8 换成 PA9；蓝灯重复一次，换成 PA10。

电阻也可以放到 LED 阴极和 GND 之间，作用一样。
**三颗灯必须三只电阻，不能三颗灯共用一只，也不要把裸 LED 直接接 GPIO。**
这里的电阻是“串联”：从 GPIO 到 GND 的电流必须经过它。

上电检查：首页居中时绿色，偏离中心红灯逐渐变亮、绿灯渐暗；其他页正常呼吸，保存时绿蓝，相关故障页红色柔和脉冲。当前固件为 2kHz 硬件 PWM，色彩渐变，无需改接线。
运行中倒置或过度倾斜时会提示 FLIP BOARD / TILT RANGE，不再确认水平或鸣叫；放回正常姿态后恢复，RAW DATA 仍可查看。
有些灯此刻本来就不会亮，先切换页面和摆动板子观察，不要只因某颗暂时不亮就重接。
本接法不是共阳 RGB 或自带驱动的灯板接法。

## 第 5 步：接 DHT11 和 4.7kΩ

### 三针小板

按小板丝印接，不按插针从左到右的位置猜：

| DHT11 小板丝印 | 接到 |
|---|---|
| VCC / + | 3.3V 红轨 |
| GND / − | GND 蓝轨 |
| DATA / S / OUT | 核心板 PA1 |

小板已有 DATA 上拉电阻时可不额外加；不确定时可加一只 4.7kΩ 从 DATA 到 3.3V。

### 四脚裸 DHT11

常见蓝色裸 DHT11：栅格正面朝你、引脚向下，从左到右通常如下。
若实际器件标记或封装不同，以型号资料为准。

| 裸 DHT11 脚 | 接到 |
|---|---|
| 1，VCC | 3.3V |
| 2，DATA | PA1 |
| 3，NC | 空着 |
| 4，GND | GND |

再加 DATA 上拉：

```text
3.3V ── 4.7kΩ ──┬── DHT11 DATA
                └── STM32 PA1
```

实际操作：PA1 与 DATA 用线直接连；4.7kΩ 一头接这条 DATA 线所在排，另一头接 3.3V 红轨。
**4.7kΩ 不是串在 PA1 与 DATA 中间，也不是接到 GND。**
这叫“上拉”：电阻是一条从信号线分出去、接向 3.3V 的支路。
裸器件可在 VCC/GND 之间靠近传感器加一只 100nF（104）陶瓷电容，无正负；模块通常自带去耦。

3.3V 方案依据奥松 DHT11 V1.3；更早版本或不同模块需按实际型号核对：
[奥松产品手册](https://www.aosong.com/userfiles/files/media/DHT11-V1_3%E8%AF%B4%E6%98%8E%E4%B9%A6%EF%BC%88%E8%AF%A6%E7%BB%86%E7%89%88%EF%BC%89.pdf)。

上电后转到 CLIMATE，等约 5–8 秒，应出现温度和湿度；此后约每 2.5 秒更新一次。
一直 -- / WAIT：先查 3.3V、共地、PA1 是否确实接 DATA，再查 DATA 上拉；详细 E/N/P/TRY 诊断行在 DEBUG 页。
手靠近传感器观察变化即可，不要往传感器上滴水。

## 第 6 步：接 W25QXX Flash 小板

下面按带丝印的小模块接，不是按裸八脚芯片封装的左右位置接。
先确认是标准 3.3V W25Q 模块；1.8V 型号不能套这个供电表。

| Flash 小板丝印 | 核心板 / 电源 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| CS / NSS | PA4 |
| CLK / SCK | PA5 |
| DO / MISO | PA6 |
| DI / MOSI | PA7 |

这六根直接接，不串 330Ω 或 4.7kΩ。
DO 是 Flash 向核心板输出，DI 是核心板向 Flash 输入，别把两根交叉。

若模块还引出 WP / HOLD 且没有上拉，分别加一只 10kΩ：

```text
3.3V ── 10kΩ ── WP
3.3V ── 10kΩ ── HOLD
```

两脚分别接各自的电阻，不接 PA6/PA7，也不接 GND；已有板载上拉时不用重复。
在当前单线 SPI 用法下，WP / HOLD 也可以直接固定到 3.3V；使用上面的两只 10kΩ 接法即可。
如果丝印是 IO2/IO3 或器件没有这些脚，先按具体模块资料确认，不盲猜脚序。

接好后上电或按 RESET，转到 SYSTEM：

1. 应有实际 Flash ID 和容量，状态最终为 READY。
2. 例如 EF4017 对应 8192KB，EF4018 对应 16384KB。
3. 转到 CLIMATE 等数值出现，保持有效温湿度约一分钟后会自动记录；有独立 PB10 按钮时也能短按，先 SAVING 再 SAVED。
4. HISTORY 应能看到新记录；停留约 0.8 秒自动进入 BROWSE，再旋转查看。两端继续旋转可退出，无需按钮。
5. 断电、重新上电，记录应还在。

Flash 在启动时识别，补接后要复位。当前支持标准 W25Q20–128。
ABSENT 先查电源和六根线；UNSUP 是未支持的 ID；LOCKED 是记录区存在未知原数据，不要靠乱接线解决。
资料入口：[Winbond 官方手册](https://www.winbond.com/hq/support/documentation/?__locale=en&pno=W25Q128JV)。

## 电阻摆放速查

| 场景 | 正确位置 | 是否必须新加 |
|---|---|---|
| 三颗裸 LED | 每颗 GPIO → 330Ω → LED → GND | 是，每颗一只 |
| DHT11 DATA | DATA → 4.7kΩ → 3.3V | 裸器件要有；模块已有上拉可不加 |
| Flash WP | WP → 10kΩ → 3.3V | 板载已有上拉可不加 |
| Flash HOLD | HOLD → 10kΩ → 3.3V | 板载已有上拉可不加 |
| 裸编码器 A/B/按压 | 直接到 PB0/PB1/PB10 | 当前固件内部上拉，不必加 |
| VCC / GND 供电线 | 直接接对应电源轨 | 不串这些电阻 |

原蜂鸣器上电若持续乱响，可加 PB8 → 10kΩ → 3.3V；原来正常就保持旧接法。

## 最后统一核对

- PA1 是 DHT11，不是 PB1；PB1 是编码器 B。
- Flash 是 PA4/5/6/7；原 I2C 是 PB6/7，这两组互不相同。
- 编码器按压是 PB10；蓝 LED 是 PA10，不是同一脚。
- 三颗 LED 分别一只 330Ω；DHT 的 4.7kΩ 是接向 3.3V 的支路。
- 已确认的裸编码器 C 与按压另一脚都接 GND，没有电源输入脚。
- 每完成一步，先验收该步再加下一块；出现问题时只排查最近新增的接线。

## 新版屏幕的正常现象

- 首页、温湿度和历史页的大号数值会右对齐，小数点位置固定；跨十位或正负变化时数字不会左右跳。
- 板子放稳且不操作 45 秒，屏幕会逐渐变暗，画面不会关闭；转编码器、按独立按钮或累计倾斜至少 0.3° 会恢复亮度。
- 校准和故障提示保持亮屏。变暗期间传感器和自动记录仍在工作，不要因为屏幕变暗就重接电源。
- 角度算法适用于水平附近；倒置显示 FLIP BOARD，大幅倾斜导致 Z 分量不足时显示 TILT RANGE，这时不记录有效角度。
- OLED 运行中断线后程序每 500ms 尝试重配置，恢复后完整补刷；实际掉线恢复和新增操作需烧板验收。
