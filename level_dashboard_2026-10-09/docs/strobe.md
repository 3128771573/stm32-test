# 红蓝灯效：STROBE 页面

新页面在 DEBUG 后面。继续使用已有两颗裸灯：红灯 PA8、蓝灯 PA10，各自串 330Ω，阴极接 GND；不需要改线。
绿色 PA9 在灯效页保持熄灭。

![实际固件绘制的精简模式页与关闭档](strobe.png)

## 不用按钮也能换模式

1. 旋转到 STROBE，立即播放上次选择的节奏；开机默认 DOUBLE。
2. 停留约 0.8 秒，右上 PLAY 变 MODE，随后旋转选择模式。底部五个小点表示当前档。
3. 正向依次为 OFF → ALT → DOUBLE → TRIPLE → CHASE，反向依次返回。
4. 在 OFF 继续反向转，退出到 DEBUG；在 CHASE 继续正向转，退出到 RUNTIME。
5. 退出后灯光恢复原来的呼吸或首页偏移效果。再次进入仍保留本次开机的模式；复位恢复 DOUBLE。

快速连续旋转仍用于翻页；另接了 PB10 独立按钮时，可短按切换 PLAY/MODE，长按约 0.8 秒回首页。
此页短按用于编辑模式，不保存记录；自动温湿度记录照常进行。

## 节奏

| 档位 | 效果 | 一个完整红蓝周期 |
|---|---|---:|
| OFF | 红、绿、蓝全部熄灭 | — |
| ALT | 红亮 160ms、暗 40ms，然后蓝亮 160ms、暗 40ms | 400ms |
| DOUBLE | 红连闪两下、停顿，蓝连闪两下、停顿；每下亮 70ms | 800ms |
| TRIPLE | 红连闪三下、停顿，蓝连闪三下、停顿；每下亮 45ms | 960ms |
| CHASE | 红蓝短闪追逐四轮，再一起停顿 200ms；每下亮 60ms | 1000ms |

红蓝各自的亮灭边沿清晰，不加入呼吸缓动；不同时点亮红和蓝，不混入绿灯。
沿用 TIM1 的 2kHz PWM，亮时 CCR=3600、暗时 CCR=0；灯效时序每 1ms 计时，输出每 5ms 更新。
OLED 只显示模式名、PLAY/MODE 状态和五档选择点；进入页面后约两秒显示简短操作提示。真实闪烁比 OLED 画面快，具体脉冲以实体 LED 为准。

灯效页保持屏幕亮度，后台的传感器、趋势、记录和按键消抖继续工作。
换模式从新节奏开头重新播放，不写入 Flash 配置，不改变已有记录格式。

## 烧录后看这几项

- STROBE 默认出现 DOUBLE，红两下后蓝两下，绿灯不亮。
- 停留后 MODE 可旋转切换；OFF 三灯全灭，其余三种节奏能区分。
- OFF 左端、CHASE 右端均能退出；退出恢复状态灯，再进入保留选择。
- 连续切换、翻页不冻结；CLIMATE 继续出值，已有 Flash 历史记录仍可读。

软件已检查节奏、脉冲次数、PWM 范围及退出恢复；实际亮度和节奏观感由板上验收确认。
