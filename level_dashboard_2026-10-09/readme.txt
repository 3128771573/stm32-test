# STM32 多功能小仪表

STM32F103C8T6 + MPU6050 + SSD1306 I2C OLED + W25QXX + DHT11 + 旋转编码器 + 三色状态灯。
基于 ST 标准外设库 V3.5.0 / Keil AC5，全部整数运算。

这是 `level_dashboard_2026-10-09/` 独立版本工程，源码、标准库及 Keil 工程均在本目录。
更新内容和升级验收见 [CHANGELOG.md](CHANGELOG.md)；原七阶段水平仪保留在仓库的 [level/](../level/README.md)。
可直接烧录 [新版 HEX](firmware/level.hex)，或用 [上一轮七页版 HEX](firmware/level_previous.hex) 回退对照。

当前为 2026-10-09 多功能版：七页仪表、编码器翻页、温湿度、掉电保存的循环记录、原始数据和实时趋势。
原七阶段版本有实物验收记录；本优化版已编译和逻辑校验，尚需用户烧板验收。

## 接线与使用

新增模块和电阻的逐步接法见 [新手接线教程](docs/wiring-beginner.md)，包含 A/C/B 编码器辨认、LED 串联电阻和 DHT11 上拉电阻的具体位置。

| 核心板 | 模块 | 说明 |
|---|---|---|
| 3.3V | OLED / MPU6050 / 蜂鸣器 VCC | 当前这套模块统一用 3.3V |
| GND | 三个模块 GND / ST-Link GND | 共地 |
| PB6 | OLED SCL + MPU6050 SCL | 共用软件 I2C |
| PB7 | OLED SDA + MPU6050 SDA | 共用软件 I2C |
| PB8 | 蜂鸣器 I-O | 低电平响 |
| PA13 / PA14 | ST-Link SWDIO / SWCLK | 下载与调试 |
| PC13 | 板载 LED | 低电平亮，无需接线 |

![接线图](docs/wiring.png)

OLED 是 **4 针 I2C**，地址 0x3C（7 位）/ 0x78（8 位写地址）。
按手上模块的 GND / VCC / SCL / SDA 丝印接线，部分资料的电源顺序相反。
MPU6050 地址 0x68，AD0 悬空（模块已有下拉）；INT / XDA / XCL 不接。
核心板自己供电时，ST-Link 的 3.3V 不接。

1. 水平放稳后上电，蜂鸣器短鸣自检。
2. 校准界面显示 `HOLD STILL` 和细进度条，采 100 点，正常约 1 秒。
3. 缺少有效样本、明显晃动或 Z 分量过小时拒绝校准，显示 `PLACE FLAT` 并自动重试；传感器未就绪时显示 `CHECK SENSOR`。校准在后台进行，可以切到其他页。
4. 左侧气泡与右侧角度跟随倾斜；持续进入水平区后，右上显示 `LEVEL`，短鸣一次。
5. 离开水平区后右上显示 `TILT`，再次摆平才会再次短鸣。

零点是开机姿态，并非工厂标定的绝对水平。校准时务必放平；要改零点请复位。
原硬件记录：这块 MPU6050 的 1g 约 18400 LSB。保留相对基准算法，避免依赖标准 16384 标度。
当前角度仍是小角度近似，适用于水平附近；气泡 ±15° 满量程，超过后沿原方向限幅。
运行中倒置时显示 `FLIP BOARD`；原始或滤波后的 Z 分量小于校准 Z 的四分之一时显示 `TILT RANGE`。
这些姿态不判水平、不触发水平提示鸣叫，也不把角度作为有效值写入记录；RAW DATA 仍能查看原始测量。

实物 A/C/B 编码器没有引出的按压接口，PB10 可以空着。历史页有记录时停留约 0.8 秒自动进入 `BROWSE`，
旋转选择新旧记录；最新记录继续向更新方向旋转回 CLIMATE，最旧记录继续向更旧方向旋转到 SYSTEM。
快速连续旋转仍用于翻页，无记录时不会进入浏览。接了独立 PB10 按钮时仍可短按切换浏览和手动保存。

屏幕静置 45 秒后渐暗，保留画面；旋转、按键、相对静置基线累计至少 0.3° 的角度变化或故障提示会恢复亮度。
校准和故障提示保持亮屏，传感器采样、灯光及自动记录继续运行。

扩展模块的接线与操作见 [多功能仪表接线和验收](docs/dashboard.md)。

## 这版为什么这样改

- **连续滤波**：旧版每帧清空滤波状态，新版只在校准或故障恢复时初始化。
  小幅变化用 alpha=1/16 抑制抖动；偏差超过 600 LSB 时，三轴一起切到 alpha=1/4 加快跟随。
  Q8 保存内部精度，负数用乘法而非左移。
- **采样优先**：SysTick 提供 1ms 时钟，目标每 5ms 读一次加速度。
  主循环不补读错过的样本；I2C 是共享总线，实际间隔仍有短事务造成的少量抖动。
- **短块差分刷新**：额外 1024 字节记录上次成功发送的画面。
  每步至多发 32 字节，块间回到主循环采样；静止且像素不变时不发送画面数据。
  首页目标每 33ms 出一帧（约 30Hz），其他页 50ms（20Hz），实际速度取决于总线速度与变化区域。
  SSD1306 没有原子整帧交换，短块刷新也不是硬件双缓冲。
- **非阻塞提示**：正常运行的蜂鸣器 100ms 短鸣、每秒 30ms 心跳都由截止时间控制。
  鸣叫期间继续采样和绘图。初始化允许短暂同步延时；校准改为后台采样，保持页面可操作。
- **稳定判定**：双轴均在 1.0° 阈值内保持 100ms 才确认水平；任一轴达到 2.0° 并保持 100ms 才退出。
  水平指示和蜂鸣器共用同一状态，避免边界附近反复闪烁和鸣叫。
  数字末位另加滞回，气泡和判定不使用冻结后的显示数字。
- **通信恢复**：MPU 配置每次写入都检查 ACK，并回读五个配置寄存器。
  连续 100ms 无有效采样显示 `CHECK SENSOR`、关闭水平提示，每秒尝试恢复总线及重新初始化。
  恢复后沿用开机零点，重新初始化滤波。OLED 写失败不确认缓存，每 500ms 尝试逐条检查 ACK 的重配置，
  恢复后完整补刷，不连续重复访问掉线的屏幕。
- **界面收简**：日常页去掉常驻页码、底栏和分隔线，保存提示只临时出现在右上。
  首页圆盘半径 28px，气泡半径 6px，双层轮廓和小高光；中心用四个小定位角，保留原实测方向。
  气泡使用 Q8 亚像素位置、约 45ms 缓动及像素滞回，显示变化更稳；温湿度故障码集中在 DEBUG。
  首页、温湿度和历史页的大号数值占五个字符位并右对齐，小数点固定在第四位，正负变化和跨十位时不横跳。
  静置渐暗将 OLED 对比度从 0xCF 渐降至 0x28，不关屏；角度变化按累计差判断，慢慢倾斜也能唤醒。

SysTick 负责时间、输入消抖和灯光包络，不在中断里操作 I2C。TIM2 用于 1MHz 微秒延时，避免与 SysTick 调度冲突。
后续扩展请保留这两个计时资源，或统一迁移计时方案。

三色 LED 使用 TIM1 硬件 PWM（PA8/9/10，2kHz、3600 级），5ms 更新呼吸曲线和 300ms 渐变换色。
首页有效时红灯亮度随偏离中心的距离增加，绿灯相应减弱；15° 径向偏移时封顶，加入约 60ms 平滑。
其他页面正常呼吸周期 3 秒，采用缓起缓落和视觉亮度补偿；保存提示至少保持约 500ms。
SysTick 同时负责编码器消抖和灯光包络，不产生软件 PWM；DHT11 修复后已由用户确认正常读取。

RAW DATA 显示 MPU 六轴及温度寄存器原始值；TREND 显示最近约 12 秒的俯仰/横滚曲线，断线留空。
DEBUG 显示 DHT 原始帧、错误与边沿计数、RGB PWM 计数、编码器电平、有效采样率、绘图帧率和 MPU 读取错误累计。
为取得全部 MPU 数据，采样从连读 6 字节改为连读 14 字节，目标仍为每 5ms 一次；实际速率可在 DEBUG 查看。

## 编译与烧录

- Keil 5 打开 `MDK-ARM/level.uvprojx`，F7 编译、F8 下载。
- 命令行：在本版本目录 `level_dashboard_2026-10-09` 执行 `build.cmd`。
- 预编译固件见 `firmware/level.hex`，校验值见 `firmware/SHA256SUMS.txt`。
- 自行编译后生成 `MDK-ARM/Obj/level.hex`；该路径的编译产物不入库。
- 编译器 ARM Compiler 5.06 update 7；器件宏 `STM32F10X_MD,USE_STDPERIPH_DRIVER` 在工程设置里。
- `build.cmd` 会查找 UV4，并把 Keil 的退出码传回调用者。
- 源码 / `readme.txt` 使用 GBK，README 使用 UTF-8；批处理使用 CRLF。

## 可调参数

参数集中在 `USER/main.c`：

| 参数 | 当前值 | 作用 |
|---|---:|---|
| `SAMPLE_INTERVAL_MS` | 5 | 目标采样间隔 |
| `DISPLAY_INTERVAL_MS` | 50 | 其他页面目标帧间隔 |
| `LEVEL_DISPLAY_INTERVAL_MS` | 33 | 首页目标帧间隔 |
| `IDLE_DIM_MS` | 45000 | 静置渐暗等待时间 |
| `HISTORY_PAUSE_MS` | 800 | 历史页自动进入浏览的停留时间 |
| `LPF_SHIFT` / `LPF_FAST_SHIFT` | 4 / 2 | 稳定 / 快速滤波强度，值越大越平滑 |
| `LPF_FAST_LSB` | 600 | 切换快速跟随的三轴偏差阈值 |
| `PITCH_DIR` / `ROLL_DIR` | -1 / 1 | 角度方向 |
| `LEVEL_ENTER_X10` / `LEVEL_EXIT_X10` | 10 / 20 | 进入 / 退出阈值 |
| `LEVEL_HOLD_MS` / `LEVEL_EXIT_MS` | 100 / 100 | 判定保持时间 |
| `BEEP_MS` / `BOOT_BEEP_MS` | 100 / 60 | 正常提示 / 开机自检，0 表示关闭 |
| `CAL_MOTION_LSB` | 1200 | 校准期间每轴峰峰值上限 |
| `READ_TIMEOUT_MS` | 100 | 读失败显示错误的时间 |

气泡的 15° 满量程映射与 45ms 缓动在 `dashboard.c` 的 `bubble_target` / `bubble_update` 中设置，方向继承俯仰和横滚。

总线速度保留原值：`USER/i2c.h` 的 `I2C_DELAY_LOOPS=8`，历史估算约 250kHz。
长线或接触不良时可调到 12–20；帧率会下降，但采样仍在短块之间执行。

## 验证与板上验收

软件验证结果见 `docs/validation.md`。请烧录后检查：

1. 放稳上电：进度条完成，约零度，出现 `LEVEL` 后短鸣一次。
2. 缓慢倾斜：气泡和数字方向正确；放稳后末位和气泡不明显抖动。
3. 快速倾斜再停住：气泡跟得上，停住后平稳收敛，无明显跳动或拖尾。
4. 从倾斜摆平：鸣叫期间画面持续更新；在 1–2° 附近停留不反复鸣叫。
5. 校准期间晃动：失败后出现 `PLACE FLAT`，放平放稳后显示 `HOLD STILL` 并自动重试。
6. 短时断开 MPU 的 SCL/SDA：出现 `CHECK SENSOR`；恢复接线后返回主界面。
7. 持续运行几分钟：没有花屏、死机或持续蜂鸣。实际帧率和手感以板上结果为准。
8. 历史页有记录时停留约 0.8 秒：标题变为 `BROWSE`，无需按钮即可选择记录；两端继续旋转能离开历史页。
9. 放稳且不操作 45 秒：屏幕逐渐变暗，画面仍可辨认；转编码器或慢慢倾斜至少 0.3° 后恢复亮度。
10. 校准完成后倒置或大幅倾斜：显示 `FLIP BOARD` / `TILT RANGE`，不假判水平；放回正常姿态后恢复。
11. OLED 运行中掉线再恢复：重配置后完整补刷；这项及新增操作仍需板上验收。

## 排查

| 现象 | 检查 |
|---|---|
| 无屏，LED 闪 3 次 / 5 次 | 只有 MPU / 两个器件都没找到，检查供电、共地、SCL/SDA |
| `HOLD STILL` / `PLACE FLAT` | 正在校准 / 校准未通过；保持板子正面朝上、水平放稳 |
| `CHECK SENSOR` | 传感器未就绪或运行中采样失败，检查接触；程序自动重试 |
| `FLIP BOARD` / `TILT RANGE` | 倒置 / 超出当前姿态范围，放回正面朝上的水平附近 |
| 静置后屏幕变暗 | 45 秒静置渐暗功能；转编码器、按独立按钮或倾斜可恢复 |
| 校准后零点偏 | 校准时未水平放稳，复位重新校准 |
| 上电蜂鸣不停 | 检查 PB8；模块悬空触发时可加 10k 上拉到 3.3V |
| 花屏 | 检查供电、共地和线材，适当增大 I2C 延时 |

## 文件与来源

`USER/main.c` 负责校准、滤波、调度、界面及提示；`oled.c` 负责绘图和差分刷新；
`mpu6050.c` / `i2c.c` 为传感器及总线驱动；`delay.c` 提供时钟；`led.c` / `buzzer.c` 控制提示。
`Libraries` 为 ST 标准外设库；`MDK-ARM` 为 Keil 工程；`docs` 为接线和验证资料。
新增 `controls.c` / `dht11.c` / `w25qxx.c` / `logger.c` / `dashboard.c` 分别负责输入和灯光、温湿度、SPI Flash、掉电记录和页面。
旧配图 wiring.png、diagram_block.png、diagram_flow.png 是原水平仪资料；新增接线以 docs/dashboard.md 为准。

PC 仿真框架已按要求删除。参考资料 `files/` 和密钥 `.ssh/` 不入库。
ST 标准库未改动；8×16 字库来自中景园 / 江协科技教学例程，版权归原作者，仅供学习。
新增 5×7 大写字母点阵在 `oled.c` 内。
